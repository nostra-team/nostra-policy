# nostra-policy

**Nostra - 로또의 모든것** 앱의 개인정보처리방침을 담은 정적 페이지.

- 공개 주소: https://software-lucas.github.io/nostra-policy/
- 이 주소를 Google Play Console 과 App Store Connect 의 개인정보처리방침 URL 에 넣는다.

앱 코드는 [software-lucas/nostra](https://github.com/software-lucas/nostra) 에 있다.
방침이 바뀌면 `index.html` 의 본문과 머리말의 **최종 수정** 날짜를 함께 고친다 —
날짜만 남고 내용이 안 바뀌거나, 내용만 바뀌고 날짜가 그대로면 심사에서 문제가 된다.
